# Commit Standards Rule

## Git Commit Language & Format
1. **Language Requirement**: All Git commit messages (subject and body) MUST be written in **English**. Never use other languages in commit messages.
2. **Conventional Commits**:
   - Follow the Conventional Commits specification:
     `<type>(<scope>): <concise summary in imperative mood>`
   - Valid types: `feat`, `fix`, `refactor`, `perf`, `test`, `build`, `ci`, `docs`, `chore`.
3. **Commit Body**:
   - Detail the reason for the change, implementation specifics, cross-platform safety considerations, and automated test verification evidence.
