# 当前功能状态

本表描述实现状态。只有实际执行过的验证才算验收，不能用格式扩展名清单代替运行证据。

| 功能 | 当前实现 | 尚待完成或验证 |
| --- | --- | --- |
| 工作区 | 通用文件树、多个目录、标签、分栏、最近项目与会话恢复 | 完整跨平台业务旅程与窗口间状态回归 |
| 文本/源码 | 通用编辑器、基础编辑、自动/显式保存、草稿、查找替换 | 大文件编辑与退出恢复的完整 UI 验收 |
| Markdown | TextView、表格、图片、任务控件、预览/源码、Mermaid | 深层嵌套任务交互、各图表类型与复杂排版回归 |
| HTML | 通用 TextView，不执行脚本 | 不是浏览器；页面脚本和复杂 CSS 不在当前阅读能力内 |
| 数据 | JSON 系列树/图、CSV/TSV 表格、SQLite 只读快照 | 逐格式的大文件、刷新和交互验收 |
| 图片 | Rust 解码，GPUI 图片、GIF 与 SVG | 特殊系统图片格式与极端尺寸输入的覆盖 |
| PDF | 私有磁盘快照，按页 Rust 渲染、翻页及图像详情 | 文本搜索/选择、密码输入、复杂页面和取消延迟 |
| Office | DOCX/PPTX/ODT/ODP 文本，XLSX/XLSM 保存值数据表 | 图片型文档、复杂排版、旧 Office、iWork、嵌入对象与专业编辑未实现 |
| 电子书/导图 | EPUB/FB2、漫画图像、XMind/OPML/draw.io 相关通用视图 | 阅读位置、复杂资源与跨窗口交互验证 |
| OpenAPI | 契约索引通过通用表格展示 | 专用接口导航、参数/响应详情与搜索体验仍需完善 |
| 压缩包 | ZIP、TAR 及常见压缩流的 Rust 服务 | TAR 链接和其余归档格式；Windows ZIP 链接受系统创建权限限制 |
| SSH/SFTP | OpenSSH 后台传输、GPUI 认证窗口 | Windows 上远程 POSIX 路径与完整认证/断线旅程仍需适配、验证 |
| 字体/音视频/OCR | 保留功能需求与格式信息 | 通用预览、播放、完整编解码和 OCR 尚未完成，不能声明为已支持 |
| 平台 | Windows 已构建并运行；四目标构建工作流已添加 | macOS、Linux 原生构建与运行验收尚未执行 |
| 发布 | 独立名称、数据目录、版本与基本构建入口 | 正式安装、签名/公证、关联注册、发行校验和更新方案 |

当前没有正式发布版本。`assets/format-catalog.json` 是格式识别与候选路由目录；其中包含的后缀并不意味着本表待办已经实现。
